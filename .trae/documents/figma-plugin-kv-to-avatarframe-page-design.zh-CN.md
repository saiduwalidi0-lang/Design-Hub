# Figma 插件页面设计说明（桌面优先）

## 全局样式（适用于全部页面）
- 画布/容器：Figma 插件面板（推荐宽 420px，高自适应；最小宽 320px）。
- 布局：整体使用 Flexbox（纵向堆叠）；局部表单区用 CSS Grid（两列：label / control）。
- 间距：8/12/16/24px 递进；卡片圆角 8px；分割线 1px（#E6E6E6）。
- 字体：系统字体；字号层级 12/14/16/20；标题半粗。
- 颜色：
  - 背景 #FFFFFF；文本 #1A1A1A；次级文本 #666666
  - 主按钮 #0D99FF（hover #007BE5）；危险 #F24822（hover #D73712）
  - 成功状态 #14AE5C；警告 #FFCD29
- 组件状态：
  - Button：默认/hover/disabled；loading 显示 spinner + 文案“生成中…”
  - Input：错误态红色描边 + 错误文案（单行）
  - Toast：成功/失败/信息三类，3s 自动消失，可手动关闭
- 动效：仅使用轻量过渡（150ms ease）用于 hover、展开/收起。

## 页面 1：插件主面板

### Meta 信息
- Title：KV 导出与生成
- Description：从选中 Frame/Group 导出 KV，生成三元素与合成并进入回写。
- Open Graph：og:title 同 Title；og:type=website（占位）；og:image=空（插件内可不填）。

### 页面结构
- 顶部：标题栏（左：插件名；右：入口按钮「设置」）。
- 主体：4 个纵向卡片区块（选择/导出、生成参数、任务状态、任务历史）。
- 底部：主操作区（主要按钮固定在底部，避免滚动丢失）。

### Sections & Components
1. 标题栏（Sticky）
   - 文本：插件名 + 简短副标题（可选）。
   - IconButton：「设置」进入 /settings。
2. 选择与校验卡片
   - 行 1：只读字段「当前选择」= 节点名 + 类型徽标（Frame/Group）。
   - 行 2：校验结果（✅可用 / ⚠️不可用）+ 原因说明（如“请选择一个 Frame 或 Group”）。
   - 主按钮：
     - 「重新读取选择」（触发重新解析当前 selection）
3. KV 导出卡片
   - 文本区（只读、多行）：展示导出的 KV JSON（折叠显示，支持展开）。
   - 按钮：
     - 「复制 KV」：复制到剪贴板并 Toast。
4. 生成参数卡片（Grid 表单）
   - 字段（最小必需）：
     - 头像框尺寸（宽/高，数字输入，带 px 后缀）
     - 风格/主题（单行输入或下拉，取决于服务要求）
     - 生成内容（Checkbox：三元素、合成；默认全选）
     - 命名前缀（输入框，默认使用选中节点名）
   - 校验：尺寸必须为正整数；至少勾选一种生成内容。
5. 任务状态卡片
   - 状态条：Idle / Running / Success / Failed（颜色 + 文案）。
   - 进度信息：阶段文案（“上传 KV/排队/生成/下载结果”）+ 耗时。
   - 操作：
     - 主按钮「开始生成」
     - 次按钮「取消」（仅 Running 时可用）
     - 链接「查看详情」跳转 /preview/:taskId（成功或失败均可）。
6. 任务历史卡片
   - List（最多 10 条）：时间、节点名、状态、进入按钮。
   - 空态：说明“尚无任务，先生成一次”。

## 页面 2：预览与回写页

### Meta 信息
- Title：预览与回写
- Description：查看三元素与合成结果，并回写为分图层头像框 Frame。
- Open Graph：同上（占位）。

### 页面结构
- 顶部：返回（回到主面板）+ 当前任务信息（节点名/时间/状态）。
- 中部：左右两栏（在 420px 面板内表现为上下折叠：先预览后回写设置）。
- 底部：主要按钮「回写到画布」。

### Sections & Components
1. 任务信息区
   - Badge：Success/Failed；失败时显示错误摘要与「重试」按钮（回到主面板并复用参数）。
2. 结果预览区
   - Tab：
     - 「三元素」：3 张图的网格缩略图（2 列）+ 点击打开大图预览（Modal）。
     - 「合成」：1 张大缩略图 + 大图预览。
   - 每张图操作：下载（可选）、复制图片到剪贴板（可选，若实现成本高可不做）。
3. 图层映射与命名区
   - 表格（两列）：元素类型（主体/装饰/文字/合成）| 写入图层名（可编辑）。
   - 命名规则辅助：前缀输入 + 自动填充按钮「按规则生成」。
4. 回写配置区
   - 单选：回写位置（当前页面 / 新建页面）。
   - 单选：容器（新建头像框 Frame）。
   - Checkbox：同时写入合成参考图（默认勾选）。
5. 回写执行与回滚
   - 主按钮：「回写到画布」loading 时禁用所有表单。
   - 成功态：Toast + 按钮「定位到新建 Frame」。
   - 危险操作：「回滚本次写入」二次确认弹窗。

## 页面 3：设置页

### Meta 信息
- Title：设置
- Description：配置生成服务地址、鉴权与默认参数。
- Open Graph：同上（占位）。

### 页面结构
- 顶部：返回主面板。
- 主体：两张卡片（服务配置、默认参数）。
- 底部：保存/重置。

### Sections & Components
1. 服务配置卡片（Grid 表单）
   - 服务 Base URL（必填，URL 校验）。
   - Token/Key（必填/可选取决于服务；输入为 password 类型，可“显示/隐藏”）。
   - 超时（秒，默认 60）。
   - 按钮：「测试连接」展示结果（成功/失败 + 错误详情可展开）。
2. 默认参数卡片
   - 默认头像框尺寸、默认命名前缀规则、默认生成内容勾选项。
3. 底部操作
   - 主按钮「保存」：写入 figma.clientStorage。
   - 次按钮「恢复默认」：二次确认后清空本地配置。
