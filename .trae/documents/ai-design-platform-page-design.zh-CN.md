# 页面设计说明（Desktop-first）

## 全局设计规范
### Layout
- 桌面端优先：内容最大宽度 1200px，左右留白自适应；关键区域使用 CSS Grid（两栏）+ Flex（局部对齐）。
- 响应式：
  - ≥1024px：两栏布局（左输入/右结果）。
  - <1024px：改为上下堆叠（先输入后结果），画廊改为 2 列；按钮全宽。

### Meta Information（默认模板）
- title：输入需求自动出图与设计方案 | 设计助手
- description：输入产品/页面需求，自动搜索参考图并生成结构化设计方案。
- Open Graph：og:title、og:description、og:type=website

### Global Styles（Design Tokens）
- 背景色：#0B0F19（深色） / 内容卡片：#111827
- 主色：#6366F1（indigo）
- 强调色：#22C55E（成功）/#EF4444（错误）
- 字体：
  - 基础：system-ui
  - 标题：20/24/28（根据层级）
  - 正文：14/16
- 按钮：
  - Primary：主色背景，hover 提升亮度 8%，disabled 降低不透明度
  - Secondary：描边按钮，hover 轻微背景填充
- 链接：下划线仅在 hover 时出现；外链图标提示“打开原图”
- 过渡：200ms ease-out，用于 hover、tab 切换、弹窗

## 页面 1：生成工作台
### Layout
- 页面主体为两栏 Grid：`grid-cols-[380px_1fr]`，间距 24px。
- 左侧固定为输入与参数；右侧为结果区（Tab 切换：参考图 / 设计方案）。

### Page Structure
1. 顶部导航（全局）
2. 主体两栏
3. 底部状态栏（轻量，可合并在结果区底部）

### Sections & Components
#### 1）顶部导航（Top Nav）
- 左：产品名 + 简短 tagline
- 右：外部链接（如“使用说明”），不阻塞核心流程

#### 2）左栏：需求输入卡（Input Card）
- 标题：
  - “输入你的需求”
  - 辅助文案：建议包含“目标用户/页面类型/功能点/风格”
- 多行文本框（Textarea）：
  - 支持粘贴
  - 空态占位符示例
- 操作按钮区：
  - Primary：开始生成
  - Secondary：填充示例、清空
- 参数区（紧凑表单）：
  - 风格倾向：下拉或可编辑选择（如：极简/科技/企业/电商）
  - 参考图数量：Stepper（默认 6，范围 3–12）

#### 3）右栏：结果区（Result Panel）
- 顶部：
  - Tab：参考图 / 设计方案
  - 右侧操作：保存为任务、复制方案、下载 Markdown（根据 Tab 状态启用/禁用）
- 状态展示：
  - 生成中：Skeleton（画廊占位 + 文本占位），显示“正在搜索参考图/正在生成方案”分阶段提示
  - 失败：错误卡片（原因 + 重试按钮）

##### 3.1 Tab：参考图（Gallery）
- 网格画廊：桌面端 3–4 列，自适应卡片
- 单图卡片：缩略图 + 标题（可选）+ 来源（可选）
- 交互：
  - 点击图片打开“预览弹窗”
  - 弹窗内：上一张/下一张、打开原图链接

##### 3.2 Tab：设计方案（Spec Viewer）
- Markdown 渲染容器：
  - 标题层级清晰（H2/H3）
  - 列表与表格支持横向滚动
- 方案建议结构（展示层约束）：
  - 信息架构（页面/模块）
  - 关键交互与状态
  - 视觉风格要点（配色/字体/组件风格）

## 页面 2：任务详情页
### Layout
- 单栏内容（max 960px）+ 顶部返回入口；重点是“只读回放”。

### Meta Information
- title：任务详情 | 设计助手
- description：查看本次生成的参考图与设计方案。
- Open Graph：包含 taskId（可选）

### Sections & Components
1. 顶部：返回“生成工作台”按钮 + 任务基础信息（创建时间、风格、图片数量、状态徽标）
2. 内容区：
   - 参考图画廊（同工作台）
   - 设计方案 Markdown（同工作台）
3. 操作区：
   - 复制分享链接
   - 复制方案/下载 Markdown

### 交互与状态
- 加载：展示 Skeleton，优先展示任务状态
- 错误：任务不存在/加载失败时，展示错误说明与返回入口
